# Quick Start

## Prerequisites

- Java 17+
- Gradle
- OpenAI API Key

## Build the Project

```bash
gradle build
```

## Start the Web UI

1. Set your OpenAI API key:
```bash
export OPENAI_API_KEY=your-api-key-here
```

2. Start the web UI:
```bash
./start-web-ui.sh
```

3. Open your browser:
```
http://localhost:8080
```

That's it! The Planner Agent Web UI is now running.
