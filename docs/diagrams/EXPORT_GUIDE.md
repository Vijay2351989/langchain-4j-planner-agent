# Quick Guide: Export Diagrams as PNG

This guide shows you the fastest ways to get PNG images from the diagrams.

## 🚀 Fastest Method: Screenshot

### On Mac
1. Open any diagram HTML file in your browser
2. Press `Cmd + Shift + 4`
3. Click and drag to select the diagram area
4. Release mouse - PNG saved to Desktop automatically!

### On Windows
1. Open any diagram HTML file in your browser
2. Press `Win + Shift + S` (opens Snipping Tool)
3. Select the diagram area
4. Click the save icon
5. Choose location and save as PNG

---

## 📥 Alternative: Download as SVG

1. Open any diagram HTML file
2. Click the **"Download as SVG"** button at the top
3. SVG file downloads automatically
4. Convert to PNG:
   - **Mac:** Open in Preview → File → Export → Format: PNG
   - **Windows:** Open in browser → Screenshot it
   - **Any OS:** Use online converter like cloudconvert.com

---

## 🖨️ Alternative: Print to PDF

1. Open any diagram HTML file
2. Click the **"Print to PDF"** button at the top
3. Save the PDF
4. Convert to PNG:
   - **Mac:** Open in Preview → File → Export → Format: PNG
   - **Windows:** Use online converter
   - **Any OS:** Screenshot the PDF

---

## 🎯 For Best Quality

### High Resolution (for printing or large displays)
1. Download as SVG
2. Open in Inkscape (free) or Adobe Illustrator
3. Export as PNG with 300 DPI

### Quick & Easy (for documentation or presentations)
1. Use screenshot method
2. Make sure browser is at 100% zoom (not zoomed in/out)
3. Capture just the diagram area

## 💡 Pro Tips

1. **For presentations:** Use SVG format - scales perfectly at any size
2. **For documentation:** Screenshot gives good quality and is fastest
3. **For editing:** Download SVG and edit in vector graphics software
4. **For web:** SVG is best - smaller file size, scales perfectly
5. **For email/sharing:** PNG from screenshot is most compatible

---

## 🐛 Troubleshooting

**Diagram not showing?**
- Wait a few seconds for it to load
- Refresh the page
- Try a different browser (Chrome works best)

**Download button not working?**
- Wait for diagram to fully render
- Try screenshot method instead

**Low quality PNG?**
- Don't zoom browser in/out - keep at 100%
- Use SVG export for best quality
- Or increase your screen resolution before screenshot
