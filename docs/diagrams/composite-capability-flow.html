Planner Agent - Composite Capability Execution Flow

Example: Mathematics Capability - "Calculate sum of 15, 23, 42"

🔑 Two-Tier Architecture

Tier 1: Planner selects high-level capability (Mathematics)

Tier 2: MethodFinder selects specific method (add, subtract, multiply, etc.)

This keeps planner context small while allowing unlimited methods per capability.

📋 Key Points:

  • Green Box (STEP 1): MethodFinderAgent uses LLM to select the right method from 13+ options
  • Orange Box (STEP 2): Selected method executes with parsed parameters
  • Why Two-Tier? Keeps planner context small - it only sees "Mathematics" not all 13+ methods
  • Extensible: Easy to add more methods without affecting planner
